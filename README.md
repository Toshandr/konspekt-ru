# Конспекты.ру

Некоммерческий учебный сайт с лекциями. Проект использует HTML, CSS и JavaScript без тяжёлых зависимостей и сборщиков. Сборка и локальный сервер работают на Node.js; React для текущей архитектуры не требуется.

## Требования

- Node.js 18 или новее
- npm (устанавливается вместе с Node.js)

Проверить установку:

```bash
node -v
npm -v
```

## Запуск локально

1. Откройте папку проекта в терминале.
2. Установите зависимости (в проекте нет внешних npm-зависимостей, команда безопасна и подготовит окружение):

```bash
npm install
```

3. Запустите сайт:

```bash
npm start
```

4. Откройте в браузере: <http://localhost:3000>

Команда `npm start` сначала собирает сайт в `dist/`, затем запускает Node.js-сервер. После изменения файлов выполните `npm start` повторно. Если сборка уже выполнена и нужно только запустить сервер, используйте `npm run serve`.

Порт можно изменить через переменную окружения `PORT`:

```bash
# PowerShell
$env:PORT=4000; npm start

# Linux / macOS / Git Bash
PORT=4000 npm start
```

## Сборка отдельно

```bash
npm run build
```

Результат сборки находится в `dist/`. Его можно разместить на любом статическом хостинге. Для локального просмотра используйте `npm run serve`.

## Деплой на GitHub Pages

Push в ветку `main` → GitHub Actions собирает `dist/` через Node.js и публикует его на GitHub Pages.

Один раз включите: **Settings → Pages → Source: GitHub Actions**.

Для проекта GitHub Pages путь репозитория автоматически задаётся через `BASE_PATH` в workflow.

## Курс «Объектно-ориентированное программирование»

Материал курса основан на пособиях «Объектно-ориентированное программирование. 1 часть» и «Объектно-ориентированное программирование. 2 часть» (О. В. Авсеева, М. К. Чернышов).

- Девять глав находятся в `src/lectures/OOP/lecture1.html` … `lecture9.html`. Каждая глава содержит исходные текст и примеры C++ из соответствующих страниц пособия. Переносы строк и страницы адаптированы для веб-формата; примеры кода не исправлялись.
- `routes.txt` задаёт маршруты `/oop/lecture1` … `/oop/lecture9`; `components/courses.js` содержит названия, порядок глав и описания для содержания.
- `components/oop-quiz.js` подключается только в лекциях ООП, добавляет одно короткое задание самопроверки на страницу. Это авторские задания сайта, а не текст учебника.
- Существующие стили из `style/assets` переиспользованы без добавления новых CSS-файлов. React и сторонние пакеты не требуются.
- Для проверки: `npm run build`, затем `npm run serve`, откройте `/oop/` и последовательно все девять лекций.

**Границы точности:** исходные PDF использованы как источник, но извлечение текста из PDF может искажать нестандартную верстку, формулы и таблицы. Перед публикацией стоит сверить такие места с оригиналами.
